Aplicativo de Visualização de Produtos e Itens Farmacêuticos

## Resumo

O objetivo geral deste projeto é desenvolver uma abordagem inovadora e sustentável que permita simultaneamente facilitar o acesso a medicamentos próximos à validade para a população e otimizar a gestão de resíduos farmacêuticos, reduzindo o descarte de medicamentos vencidos, contribuindo assim  para a redução do impacto ambiental negativo per capita das cidades.
